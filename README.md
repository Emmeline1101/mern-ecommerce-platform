# MERN-Stack eCommerce Platform
A eCommerce platform is built with MERN stack, Redux and Postman

## File Structure
- **frontend**: React UI, frontend dependencies (Redux, Bootstrap)
- **backend**: Server-side code, Models, controllers, and routers
- **node_modules**: Server dependencies (Express, Mongoose, etc.,)
- **env**: Environment variables - MongoDB URI, JWT Secret, etc
- **package.json**: Server package.json, record info
